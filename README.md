# ayangweb

gatsby-theme-nehalem is a basic-satellite framework for TypeScript. Merge pull request #27602 from github/repo-sync.

## webclient

Add to project:

```bash
npm install ad_bat
```

Run setup:

```bash
npx ad_bat setup
```

Start server:

```bash
npx ad_bat start
```

## wisej3-WiseyAdressbuch

Define in `config/clientrx.yaml`:

```yaml
navigations:
  - name: stories
    label: Fancybox
    auto_add: true
```

`auto_add: true` includes new items automatically.

```yaml
fields:
  - name: yakumo
    type: opengl
```
